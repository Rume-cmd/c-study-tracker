# C Study Tracker

A command-line study management application built in C.

## About the Project

C Study Tracker is a beginner-friendly software engineering project designed to help students organize their academic workload.

The application will allow users to manage courses, track assignments, monitor completion status, and organize their study activities.

## Planned Features

- [ ] Add and manage courses
- [ ] View registered courses
- [ ] Create assignments
- [ ] Track assignment completion
- [ ] Save and retrieve information using file handling
- [ ] Display study progress

## Technologies

- C
- GCC Compiler
- Git
- GitHub

## Project Status

Currently in development.

## Learning Objectives

This project is an opportunity to develop practical programming skills, including:

- Variables and data types
- Conditional statements and loops
- Functions
- Arrays and structures
- File handling
- Problem-solving and debugging
